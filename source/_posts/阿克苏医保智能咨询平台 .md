## 📋 项目概述

| 项目项          | 详细信息                                                     |
| --------------- | ------------------------------------------------------------ |
| **项目名称**    | 阿克苏医保智能咨询平台（依保儿）                             |
| **项目类型**    | H5 医保在线 AI 咨询机器人应用                                |
| **核心定位**    | 面向参保群众的 7×24 小时智能医保问答服务平台                 |
| **主要能力**    | AI 流式问答、流媒体回复、语音交互、智能问题推荐、用户反馈闭环、会话管理 |
| **UI/原型设计** | 用户自主独立设计                                             |
| **技术栈**      | Vue.js 2.x + Vant UI + WebRTC Speech API + Text-to-Audio API + ReadableStream |

**项目背景**：传统医保咨询依赖人工热线，存在服务时段受限、高峰排队拥堵、人力成本高、咨询效率低等问题。本项目依托医保专属 AI 大模型，搭建轻量化 H5 智能咨询平台，支持文字、语音多模态交互，通过智能问题推荐、流式实时回复、用户评价反馈等能力，实现医保咨询服务全天候、智能化、自助化，有效缓解人工服务压力，提升群众医保咨询体验与效率。

## 🎯 核心功能模块

### 1. 智能流式问答系统（核心模块）

- **AI 对话引擎**：深度对接阿克苏医保专属 AI 服务接口 `/aksai/v1/chat-messages`，支撑全场景医保问题智能解答。
- **流媒体响应机制**：基于 Server-Sent Events（SSE）流式传输协议，结合 ReadableStream API 实时分片处理服务端数据，无需等待完整响应即可实时渲染答案。
- **智能内容解析**：自动过滤后端冗余标签与无效信息，精准提取`</details>` 标签后的有效答复内容，保证回复简洁规范。
- **沉浸式打字机渲染**：自定义 PrinterMarkdown 组件，实现 Markdown 格式文本渐进式打字机动画效果，大幅提升对话交互质感。
- **请求中断机制**：集成 AbortController，用户发起新提问时自动终止上一条未完成的流式请求，避免无效请求堆积与页面渲染错乱。

### 2. 轻量化智能交互引导体系

针对普通用户不会精准提问的痛点，搭建多层级傻瓜式引导交互，降低使用门槛：

- **四大快捷功能按钮**：固定入口覆盖参保、报销、查询、转移四大高频医保业务，一键触发对应咨询场景。
- **猜你想问智能推荐**：内置 14 条高频医保常见问题，通过随机无重复算法展示 4 条热门问题，支持一键换刷新。
- **动态轮换动画**：问题刷新配套 360° 旋转动画，交互反馈清晰流畅。
- **对话后关联推荐**：AI 答复渲染完成后，自动请求并展示相关衍生问题，引导用户连续咨询，完善咨询链路。

### 3. 全链路语音交互系统

#### 3.1 文本转语音（TTS）

- 对接专属音频合成接口 `/aksai/v1/text-to-audio`，将 AI 文字答复实时转换为语音播报。
- 双播放模式：全局自动朗读开关（全局生效）+ 单条消息手动点击播放（按需触发）。
- 精准状态管控：通过 `activeVoiceIndex` 标记当前播放消息，杜绝多音频重叠播放。
- 智能中断重放：点击正在播放的语音可即时停止，支持重复播放，交互逻辑贴合用户习惯。

#### 3.2 语音转文本（STT）

- 基于浏览器原生 **WebKit Speech Recognition API** 实现实时录音转文字。
- 默认适配中文（zh-CN）场景，精准识别普通话医保咨询话术。
- 可配置开关设计：代码预留启用/注释切换方案，适配不同浏览器兼容性场景。

### 4. 用户反馈闭环系统

构建问答效果评价体系，持续迭代优化 AI 知识库精准度：

- **点赞功能**：用户标记有效答复，提交 `rating: 'like'` 正向反馈。
- **点踩反馈**：基于 Van ActionSheet 实现底部弹窗表单，支持预设问题原因 + 自定义文字输入，适配多样化反馈场景。
- **状态互斥机制**：单条消息点赞、点踩状态相互排斥，实时同步视图，避免状态冲突。

### 5. 会话全生命周期管理

- **上下文持久化**：通过 `conversation_id`、`message_id` 唯一标识对话，支撑多轮上下文连续问答。
- **一键清空会话**：调用批量删除接口，销毁当前会话数据，自动重置初始欢迎页面。
- **请求去重优化**：同一会话仅执行一次删除请求，防止连续点击触发重复接口调用。

## 🏗️ 核心技术架构与技术亮点

### 技术亮点 1：原生 SSE 流媒体流式解析（核心难点）

不依赖第三方流式插件，原生基于 Fetch + ReadableStream 实现长连接流式数据分片解析，渐进式渲染 AI 答复，解决传统整包返回延迟高、体验差的问题。

```javascript
// 关键实现：Server-Sent Events 流式解析
const response = await fetch('/aksai/v1/chat-messages', {
  method: 'POST',
  signal: this.controller.signal,  // 支持请求中止
  body: JSON.stringify({
    response_mode: 'streaming',
    // 对话入参
  }),
})

const reader = response.body.getReader()
const decoder = new TextDecoder('utf-8')
let buffer = ''

while (true) {
  const { done, value } = await reader.read()
  if (done) break
  
  buffer += decoder.decode(value, { stream: true })
  // 逐行切割处理流式数据
  let lines = buffer.split('\n')
  buffer = lines.pop()  // 保留未完成碎片，防止数据截断
  
  for (let line of lines) {
    if (line.startsWith('data:')) {
      const obj = JSON.parse(line.replace(/^data:\s*/, ''))
      if (obj.event === 'message' && obj.answer) {
        tempContent += obj.answer
        // 实时更新页面 UI，实现打字机效果
      }
    }
  }
}
```

**核心优势**：实时响应无等待、支持主动中止长连接、分片处理内存占用极低，适配移动端弱网环境。

### 技术亮点 2：打字机时序锁 + 错峰接口调度

严格控制接口请求时序，等待打字机动画完全渲染完毕后，再请求关联推荐问题，避免接口并发堆积、UI 渲染冲突。

**优势**：UI 渲染流畅有序、规避接口并发拥堵、用户视觉体验连贯。

### 技术亮点 3：音频任务队列生命周期管控

自研音频任务 ID 自增机制，精准过滤过期僵尸音频任务，彻底解决快速切换消息导致的多音频重叠、音频错乱问题。

```javascript
voiceTaskId: 0,        // 全局任务计数器
currentAudio: null,     // 全局音频实例

playBotVoice(idx, text, manualPlay = false) {
  const myTaskId = ++this.voiceTaskId  // 生成当前唯一任务ID
  
  // 过期任务直接失效，拒绝执行
  if (this.voiceTaskId !== myTaskId) {
    return
  }
  
  // 音频播放结束二次校验任务有效性
  audio.onended = () => {
    if (this.voiceTaskId !== myTaskId) return
    this.activeVoiceIndex = null
  }
}
```

**优势**：完美兼容自动/手动双播放模式、杜绝音频串音、任务生命周期闭环可控。

### 技术亮点 4：智能自适应滚动机制

针对聊天场景优化滚动逻辑，区分用户主动浏览与自动更新场景，兼顾新消息跟进与历史浏览体验。

```javascript
onScroll() {
  const list = document.getElementById('chat-scroll')
  const distanceToBottom = list.scrollHeight - list.scrollTop - list.clientHeight
  // 距离底部超过30px，判定为用户主动向上翻阅
  if (distanceToBottom > 30) {
    this.isAutoScroll = false
  } else {
    this.isAutoScroll = true
  }
}
```

**优势**：用户翻看历史记录不强制跳转、新消息实时自动跟进、移动端交互体验极致顺滑。

### 技术亮点 5：状态互斥与双向同步机制

点赞、点踩状态双向互斥，视图与数据状态实时同步，避免状态叠加错乱。

**效果**：单条消息仅支持单一评价状态，支持二次切换修改，交互逻辑符合用户认知。

### 技术亮点 6：无重复随机 question 轮换算法

实现「猜你想问」无重复随机刷新，保证每次轮换展示 4 个全新问题，提升内容新鲜感。

```javascript
getRandomQuestions() {
  const tempList = [...this.guessList] // 拷贝副本，不污染原数据
  const result = []
  
  // 循环随机抽取，去重填充
  while (result.length < 4 && tempList.length > 0) {
    const idx = Math.floor(Math.random() * tempList.length)
    result.push(tempList[idx])
    tempList.splice(idx, 1)
  }
  
  return result
}
```

**优势**：零重复、高效率、配合旋转动画，交互体验优质。
