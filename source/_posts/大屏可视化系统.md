# 大屏可视化系统 - 技术文档

## 一、项目概述

### 1.1 项目名称
杭州商保驾驶舱（大数据可视化展示系统）

### 1.2 定位
基于 Vue 2.6 的医疗保险数据实时展示大屏系统，通过数据可视化呈现参保人信息、理赔数据、医疗机构理赔、疾病治疗、药品使用、服务项目等核心业务数据。

### 1.3 核心技术栈
- **前端框架**：Vue 2.6.12
- **UI 库**：Element UI 2.15.13
- **图表库**：ECharts 5.4.0 + DataView 2.10.0
- **响应式缩放**：autofit.js 3.2.5
- **状态管理**：Vuex 3.6.0
- **HTTP 客户端**：Axios 0.24.0

## 四、技术亮点详解

### 4.1 响应式缩放方案（autofit.js）

**核心特性**：自动检测屏幕分辨率，动态计算并应用缩放比例。

**实现方式**：
```javascript
// home.vue mounted 生命周期钩子
mounted() {
  autofit.init({
    resize: true,  // 监听窗口变化自动调整
  })
}

beforeDestroy() {
  autofit.off()
}
```

**工作原理**：
- 设计基准分辨率：1920×1080
- 计算缩放系数：scale = 实际屏幕宽度 / 1920
- 应用 CSS Transform 进行全局缩放

**优势**：
- 无需编写复杂的 Media Query
- 自动监听窗口 resize 事件
- 保持整体设计比例一致
- 一行代码支持所有分辨率适配

**适用场景**：1080p、2K、4K 或任意非标准分辨率

### 4.2 科技感雷达波纹动画

**位置**：indexs/index.vue 的 center-map 容器

**实现**：纯 CSS 3D 动画

```scss
@keyframes radar {
  0% {
    box-shadow: 0 0 0 0 rgba(0, 150, 255, 0.3);
    transform: translate(-50%, -50%) rotate(0deg);
  }
  100% {
    box-shadow: 0 0 0 100px rgba(0, 150, 255, 0);
    transform: translate(-50%, -50%) rotate(360deg);
  }
}

.radar-effect {
  position: absolute;
  top: 50%;
  left: 50%;
  width: 500px;
  height: 500px;
  border-radius: 50%;
  background: rgba(0, 150, 255, 0.1);
  animation: radar 3s infinite linear;
  z-index: 1;
}
```

**技术创新点**：
- **无 DOM 开销** - 使用 box-shadow 实现波纹扩散
- **同步旋转与扩散** - 结合 rotate 和 scale 变换
- **透明度渐变** - 波纹逐渐变透明，视觉流畅
- **纯 CSS 动画** - 零 JavaScript 计算，性能最优

**视觉效果**：蓝色波纹以中心向外扩散，同时 360° 旋转，3 秒循环

## 五、高级功能实现

### 5.1 组件通信机制

**三层通信架构**：

**1. Props 下行传递**
```javascript
// 父组件 home.vue
<Indexs :value="value"/>

// 子组件 indexs/index.vue
props: {
  value: { type: [String, Date], required: true }
}
```

**2. Event 上行触发**
```javascript
// center-map.vue 地图交互
this.$emit('getAdmvs', selectedRegion)

// indexs/index.vue 监听事件
getAdmvs(value) {
  this.insuadmdvs = value
  // 重新查询所有 6 个数据源
}
```

**3. Vuex 全局状态**
```javascript
// 管理缩放、轮询、预警等全局配置
store/modules/setting
```

### 5.4 实时时间显示

**实现**：右上角实时显示当前时间（HH:mm:ss）

```javascript
export default {
  data() { return { timing: null, dateDay: null } },
  mounted() { this.timeFn() },
  beforeDestroy() { clearInterval(this.timing) },
  methods: {
    timeFn() {
      this.timing = setInterval(() => {
        this.dateDay = formatDate(new Date(), "HH:mm:ss")
      }, 1000)
    }
  }
}
```

**特点**：
- 每 1000ms 更新一次
- 卸载时自动清理定时器，防止内存泄漏
- 格式化为 HH:mm:ss 显示

### 5.6 加载动画与初始化

**加载流程**：
```javascript
export default {
  data() { return { loading: true } },
  mounted() {
    this.value = formatDate1(new Date())
    this.timeFn()
    this.cancelLoading()
    autofit.init({ resize: true })
  },
  methods: {
    cancelLoading() {
      setTimeout(() => {
        this.loading = false
      }, 500)
    }
  }
}
```

**HTML 模板**：
```html
<dv-loading v-if="loading">Loading...</dv-loading>
<div v-else class="host-body">
  <!-- 实际内容 -->
</div>
```

**效果**：延迟 500ms 后隐藏加载动画，展示实际内容
